# Exact signed square kernels in arbitrary-degree explicit orders

Given a monic irreducible integer polynomial and a list of nonzero elements in its rational power basis, one can recover a basis of the field-square masks and an exact root for each basis product. The algorithm factors rational polynomials and uses lattice arithmetic. It requires no integer factorization, maximal-order basis or class-group computation. Its time is polynomial in the explicit input size times \(2^r\), where \(r\) is the actual square-class rank left after ideal parity and norm sign. The same factor-free ideal calculation gives a computable upper bound on the class-group part of this rank. [Implementation and replay](../experiments/cogentic-order-square-kernel.py)

## The first kernel and a rank certificate from ideal atoms

Run the [arbitrary-degree ideal-parity algorithm](cogentic-order-ideal-parity.md), with a norm-sign row, on the supplied columns. Input \(-1\) as an ordinary column to give each mask a free sign coordinate. A square has both even ideal valuations and positive rational norm. The algorithm finds this first kernel from the explicit power order, enlarging it only where a particular ideal sum is noninvertible. It works at named small primes and unnamed composite supports without factoring the norm or discriminant.

The atom data bound the residual rank without listing any prime ideals. Let \(A_1,\ldots,A_k\) be the final invertible atoms in the working order. Their extensions to the maximal order are pairwise comaximal. For a nonsquare extended atom set \(J_j=A_j\mathcal O_K\), and for a square extended atom set \(J_j=\sqrt{A_j\mathcal O_K}\), its unique integral ideal root. This defines the ideals in the proof. Their lattices need not be constructed. Put \(b_j=1\) or \(2\), respectively, so that \(A_j\mathcal O_K=J_j^{b_j}\).

For a masked product with even ideal valuations, the exponent of every nonsquare atom is even, by disjoint supports. Hence the class of its half ideal lies in the subgroup \(G\) generated by the \([J_j]\). The original column \(i\), after scaling by a rational square to clear denominators, supplies the principal relation with exponents \((b_j e_{ji})_j\), where \(e_{ji}\) are the atom exponents in that column. Modulo two, this is exactly the ideal-parity column, padded by zeros on the square atoms. Let \(c\) be the rank of these columns, excluding norm sign. The presentation of \(G/2G\) as a quotient of \(\mathbb F_2^k\) gives
\[
 \dim G[2]=\dim G/2G\le k-c.
\]
The determinant sign is independent of the atom presentation. On the even-ideal quotient by field squares, the half-ideal map has kernel represented by units, of binary dimension \(r_1+r_2\). Positive norm removes at least one unit dimension when the field degree is odd because \(-1\) has negative norm. Therefore the actual residual rank is bounded by
\[
 r\le r_1+r_2-\mathbf 1_{d\text{ odd}}
     +\min\bigl(\dim\operatorname{Cl}(K)[2],k-c\bigr).
\]
In particular \(k-c\) is a rank certificate that uses the already computed composite ideal data. This complements the [rank certificate from named support primes](cogentic-adaptive-square-kernel.md#rank-certificates-from-principal-ideal-relations).

### Integer relations and sign rows

Keeping the integer atom exponents gives a sharper certificate. Let \(A=(b_j e_{ji})\) have \(n\) input columns, put \(C=A\mathbb Z^n\subseteq\mathbb Z^k\), and write \(Q=\mathbb Z^k/C\). Set \(\rho=\operatorname{rank}_{\mathbb Q} A\), \(V=\ker(A\bmod2)\), and \(U=(\ker_{\mathbb Z}A)\bmod2\). The map
\[
 V\longrightarrow Q[2],\qquad v\longmapsto A\widetilde v/2\pmod C
\]
is well-defined for any integer lift \(\widetilde v\), since changing the lift changes its image by a column combination. It is onto: if \(2x=Aw\), take \(v=w\bmod2\). Its kernel is \(U\), since \(A\widetilde v/2=Aw\) implies \(\widetilde v-2w\in\ker_{\mathbb Z} A\). The integer kernel is saturated and has rank \(n-\rho\), so \(U\) has this binary dimension. Equivalently, the dimension of \(Q[2]\) is \(\rho-c\), the number of nonzero even entries in the integer Smith form. The free part of \(Q\) contributes nothing. All accessible half-ideal classes in the actual class group are images of this map.

For any imposed sign rows \(S\), let \(\delta=\operatorname{rank}(S|_V)\) and \(\delta_u=\operatorname{rank}(S|_U)\). The allowed domain is \(V\cap\ker S\), and its image in \(Q[2]\) has dimension
\[
 t_+=\rho-c-\delta+\delta_u.
\]
The kernel of this map on the allowed domain has dimension \(n-\rho-\delta_u\). A lift in \(\ker_{\mathbb Z} A\) gives a unit by taking the product with those integer exponents, because its entire ideal is trivial. Other lifts of the same mask differ only by a field square. Thus for the norm-sign row one can take \(u_+=r_1+r_2-\max(\mathbf1_{d\text{ odd}},\delta_u)\) as an upper bound on the dimension of all positive-norm unit classes. Here \(\delta_u=1\) itself certifies a unit of negative norm, even in even degree. Two valid bounds on the residual rank are
\[
 r\le u_+ + \min\bigl(\dim\operatorname{Cl}(K)[2],t_+\bigr),
 \qquad
 r\le t_+ + \min\bigl(u_+,n-\rho-\delta_u\bigr).
\]
The first uses the actual half-ideal class map. The second bounds the image of the certified unit subspace and adds its codimension. The cap \(n-\rho-\delta_u\) applies to certified units because some additional half ideals may be principal in the actual field. Both sign ranks are obtainable by binary linear algebra after computing a saturated integer nullspace. The signature is obtained by real root isolation of \(P\). If the odd-degree sign column \(-1\) is present, the norm-sign row already acts on \(U\) and does not further reduce \(t_+\).

For example, the rational inputs \(pq,qr,(pq)^2\) for three distinct primes have three atoms but \(\rho=c=2\), leaving an old deficit of one and zero accessible Smith torsion. In \(\mathbb Q(\sqrt{10})\), the lone column \(1+\sqrt{10}\) has norm \(-9\) and ideal equal to the square of one of the primes above 3. Its matrix is \([2]\), and the negative norm removes the sole accessible torsion direction.

There can be no strict universal improvement from the principal relation matrix, rational norms and signature alone. Compare the lists \((-1,2+\sqrt{-5})\) and \((-1,(1+\sqrt{-2})^2)\) in their respective imaginary quadratic fields. Both have matrix \([0,2]\) and norms \((1,9)\). In the first field the half ideal of \(2+\sqrt{-5}\) is a nonprincipal prime above 3, since \(x^2+5y^2=3\) has no integral solution. Its square class is independent of \(-1\), so both slots in the bound are attained. In the second field the second column is already a square. Taking all integer powers of the supplied relations gives exactly \(C\). Saturating \(C\) at 2 would incorrectly declare the first half ideal principal. Odd saturation preserves the two-primary torsion and supplies no additional saving by itself.

Higher powers in the Smith entries can help with separate cardinality information. If the even entries have two-adic orders \(a_1\le\cdots\le a_t\) and \(|G|\le B\), then \(s\) independent images in \(G[2]\) require \(\sum_{i=1}^s a_i\le\log_2 B\). Choose \(s\) cyclic summands with independent images of their order-two elements. Their direct sum injects into \(G\), since a nonzero kernel in a finite two-group contains an element of order two. An explicit bound is obtained by taking \(M=2^d\lceil\sqrt{|\operatorname{disc}(P)|}\rceil\), which exceeds Minkowski's class representative norm bound. The number of integral ideals of norm \(n\) is at most the number of ordered \(d\)-tuples of positive integers with product \(n\), by comparing Euler factors prime by prime. The sum of these tuple counts through \(M\) is at most \(M(1+\log M)^{d-1}\), which gives a factor-free choice of \(B\). Additional certified principal relations can also shrink the available image. After adjoining them to \(C\), reduce the actual half-ideal vectors from a basis of \(V\cap\ker S\) in the enlarged quotient. Its entire two-torsion may then include directions outside the original image.

## Recovering a root from a degree-\(2d\) polynomial

Write \(K=\mathbb Q(\alpha)\), where \(P(\alpha)=0\) and \(d=\deg P\). For a nonzero candidate product \(z\), let \(h>0\) clear its coordinate denominators and put \(g=h^2z\). Use the same explicit cover algebra as in the composite parity test,
\[
 E=K[Y]/(Y^2-g).
\]
In the basis \((1,\alpha,\ldots,\alpha^{d-1},Y,\alpha Y,\ldots,\alpha^{d-1}Y)\), multiplication by \(Y+j\alpha\) has a rational matrix. Its characteristic polynomial is also the resultant
\[
 f_j(T)=\operatorname{Res}_X\bigl(P(X),(T-jX)^2-g(X)\bigr).
\]
Scan \(0\le j\le\binom{2d}{2}\) and take the first squarefree \(f_j\), retaining its matrix. Every two geometric points of \(E\) can collide for at most one scanned \(j\). This ensures that the selected element generates \(E\), even when \(z\) is a rational scalar or lies in a proper subfield.

Factor this monic integral polynomial over \(\mathbb Q\). In the nonsquare case \(E\) is a field and the polynomial is irreducible. In the square case it has two distinct factors \(f_1,f_2\), both of degree \(d\). Use the extended Euclidean algorithm to find \(u f_1+v f_2=1\) and evaluate \(J=u f_1\) on the selected matrix. Applied to the coordinate vector of one, this gives an idempotent with component values 0 and 1 under \(E\cong K\times K\). The element \((2J-1)Y\) is diagonal because the two components of \(Y\) have opposite roots. Its second block of coordinates is zero. The first block, divided by \(h\), is a root of \(z\). The implementation verifies the zero block and the final square identity using exact rational arithmetic. It reuses the cover constructor for both decisions and recovery. [Power-basis coefficient bounds](cogentic-monic-square-extraction.md) · [Deterministic rational polynomial factorization, Theorem 3.6](https://pub.math.leidenuniv.nl/~lenstrahw/PUBLICATIONS/1982f/art.pdf)

## Kernel generation and cost

On a first-kernel basis of dimension \(D\), use the [adaptive basis search](cogentic-adaptive-square-kernel.md). Keep masks for independent residual square classes. For each new basis vector, enumerate its translates by the current pivot span and apply the exact cover test until one is a square. A match returns a certified root and a new kernel vector. With no match the original vector gives a new residual pivot. The completed output has \(D-r\) independent masks and uses at most \(D2^r\) queries. If an optional query cap stops the search, every root already returned remains a certificate.

Each masked product uses each explicit input at most once. In the power basis, common denominators multiply and coefficient lengths grow by at most a polynomial in the input bit lengths, degree and number of columns. The primitive scan, rational factorization, polynomial Bézout calculation and root verification also have polynomial bit bounds. Thus after the polynomial-time ideal calculation the total bit cost is \(\operatorname{poly}(S)2^r\), and the stored basis and certificates have polynomial size in the explicit input length \(S\). On a one-third-scale list this fits the \(\exp(O(W))\) budget whenever the stated residual bound is \(O(W)\). A uniform unconditional bound on the residual rank for arbitrary fields remains open.

## Verification

Run `python3 -B experiments/cogentic-order-square-kernel.py` with SageMath. The replay compares every signed mask in four small lists in degrees 1, 2, 4 and 6 against independent number-field square decisions. It checks a query cap after a certified relation, a quartic with residual rank two, and a scaled quartic order with a 150-bit composite index base. The last fixture compares the result with its unscaled presentation and verifies every returned root directly. The kernel API returns completion, masks with roots, residual pivot count, query count, and first-kernel dimension. The separate `parity_columns` and `atom_defect` helpers expose the computable part \(k-c\) of the rank certificate.
