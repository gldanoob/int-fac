# The complexity of counting square roots in a quarter interval

For an odd $n>1$ and a supplied unit $c\bmod n$, define
$$
Q(n,c)=\#\{1\le x\le\lfloor n/4\rfloor:x^2\equiv c^2\bmod n\}.
$$
With the complete factorization supplied, the exact count takes $2^{\lceil\omega(n)/2\rceil}\operatorname{poly}(\log n)$ deterministic bit operations. With arbitrarily many prime divisors and variable $c$, computing even its parity is $\oplus\mathrm P$-complete under polynomial-time many-one reductions, including on inputs supplied with that factorization. Here $\oplus\mathrm P$ consists of decision problems that ask whether a polynomial-time verifier accepts an odd number of witnesses.

Manders and Adleman proved NP-completeness for **existence** of a bounded square root. Jansen, Klein and Lassota discuss the supplied-factorization version and strengthen its restrictions on prime exponents. The reduction below concerns **parity**, uses a fixed cutoff relative to $n$, and supplies an explicit square root $c$. [Manders–Adleman](https://doi.org/10.1145/800113.803627) · [Jansen–Klein–Lassota, §2](https://doi.org/10.1007/s10107-022-01837-0)

## Exact evaluation from the factors

Write $n=\prod_{i=1}^h d_i$ with $d_i$ the maximal prime-power blocks. For $N_i=n/d_i$, put $u_i=cN_i(N_i^{-1}\bmod d_i)\bmod n$. Each root is the reduction modulo $n$ of a unique sum $\sum_i\epsilon_i u_i$ with all $\epsilon_i\in\{-1,1\}$. Indeed, the local roots at each odd prime power are precisely $\pm c$.

Divide the blocks into halves, generate their two lists of signed sums reduced to $[0,n)$, and sort the second list. For each first-list entry $v$, count second-list entries $w$ for which $v+w$ lies in $[1,m]$ or $[n+1,n+m]$, using binary search at the endpoints. These are all possible lifts since $0\le v+w<2n$. This works for every $0\le m<n$, including $m=\lfloor n/4\rfloor$. The time and space have the stated bound since each list has at most $2^{\lceil h/2\rceil}$ entries of $O(\log n)$ bits.

## Encoding subset-sum parity in one count

Start with positive binary weights and target $0\le T\le$ their sum. Counting subsets of a given weight is $\#\mathrm P$-complete under parsimonious reductions, so deciding its parity is $\oplus\mathrm P$-complete. Append a labeled item of weight one. The number of augmented subsets with weight at most $T$ is the sum of the original counts at most $T$ and at most $T-1$. Its parity equals the original exact-weight parity. Label all augmented weights $w_1,\ldots,w_k$, and put $W=\sum_i w_i$, $L=16(W+1)$ and $\nu=2T-W+1$. [Haase–Kiefer, Proposition 2](https://archive.model.in.tum.de/um/bibdb/kiefer/16HK-IPL.pdf#page=3)

Use the first $k+1$ odd primes $p_0,\ldots,p_k$. For each, let $d_i$ be its least power reaching $16(k+1)L$, and take $n=\prod_i d_i$. Set
$$
 \alpha_0=\tfrac14-\nu/L,\qquad \alpha_i=w_i/L\quad(1\le i\le k).
$$
Choose $t_i=\lfloor d_i\alpha_i\rfloor$, incrementing it by one if $p_i$ divides it. Thus $t_i$ is a local unit and $|t_i/d_i-\alpha_i|\le 1/d_i$. With $N_i=n/d_i$, supply $c=\sum_i t_iN_i\bmod n$. Its reduction at $d_i$ is $t_i N_i$, a unit. The CRT formula above now says that $x/n$ for all roots $0\le x<n$ are exactly the fractional parts of the signed sums $\sum_i\epsilon_i t_i/d_i$, each occurring once.

For $\epsilon_0=+1$ and $S=\sum_{i\ge1:\,\epsilon_i=+1}w_i$, the signed sum differs by at most $1/(16L)$ from
$$
 \tfrac14+\frac{2S-W-\nu}{L}=\tfrac14+\frac{2(S-T)-1}{L}.
$$
The perturbed sum lies strictly between $0$ and $1/2$ because $|2(S-T)-1|\le2W+1$. It lies below $1/4$ precisely when $S\le T$, since the odd integer $2(S-T)-1$ has absolute value at least one. Every choice with $\epsilon_0=-1$ negates a sum with $\epsilon_0=+1$. Its fractional part lies strictly between $1/2$ and $1$. Consequently $Q(n,c)$ counts exactly the augmented subsets of weight at most $T$. Its parity is the required answer.

The primes can be generated by a sieve up to $O((k+1)\log(k+2))$. Each $d_i$ is smaller than $16p_i(k+1)L$, so $\log n=O((k+1)(\log(k+2)+\log(W+2)))$. All rational rounding, multiplications and reductions are deterministic polynomial-time integer operations. The construction gives the factorization along with $n,c$. Conversely, guessing $x$ in the quarter and verifying the congruence gives membership in $\oplus\mathrm P$.

## Deterministic reduction with a binary exponent

The same hardness holds if the target is given by an exponent $J$ in binary and $c=2^J\bmod n$. Modify the prime powers and the rounding in the construction above. Set $D=\operatorname{lcm}_i(p_i-1)$, and compute
$$
s_i=v_{p_i}(2^{p_i-1}-1)+v_{p_i}(D/(p_i-1)).
$$
For odd $p_i$ the lifting-the-exponent identity gives $s_i=v_{p_i}(2^D-1)$. The displayed expression avoids constructing $2^D$. Take $d_i=p_i^{a_i}$ to be the least power reaching $16(k+1)L p_i^{s_i}$. With all blocks fixed, choose $t_i$ in the class $N_i^{-1}\bmod p_i^{s_i}$ within $p_i^{s_i}$ of $d_i\alpha_i$. Consecutive members have exactly that spacing. The sum of the fractional errors is still at most $1/(16L)$.

At $d_i$ the local target $t_iN_i$ is $1\bmod p_i^{s_i}$. The element $2^D$ generates the entire subgroup of such units: its order is $p_i^{a_i-s_i}$ by the same valuation identity, and the subgroup has that size. Compute a local exponent $z_i$ one base-$p_i$ digit at a time. Given a solution $z$ modulo $p_i^h$ to $(2^D)^z\equiv t_iN_i\bmod p_i^{s_i+h}$, try $z+u p_i^h$ for $0\le u<p_i$ modulo $p_i^{s_i+h+1}$. Exactly one lifts. Start at $z=0,h=0$. CRT on the pairwise coprime local orders gives $z\equiv z_i\bmod p_i^{a_i-s_i}$, and $J=Dz$ has the required target. Each $s_i\log p_i$ is $O(p_i+\log D)$, $\log D\le\sum_i\log p_i$, and modular powering costs polynomial time in the bit lengths. Thus the enlarged $n$, the binary index $J$ and the digit searches have polynomial size and cost. The numerical value of $J$ can exceed the short index range used for two-prime inputs.

## A zero-error randomized reduction with the fixed target one

There is also an unconditional expected-polynomial-time reduction with $c=1$, still supplying the complete factorization. Its random step generates one auxiliary prime. Replace the original target $T$ by its complement if necessary so that $2T$ is at least the sum of the original weights. Complementing a subset preserves the number of solutions at the new target. Append the same dummy item of weight one, and denote the augmented weights by $w_1,\dots,w_k$ and their sum by $W$. Now $W\le 2T+1$. Put $L=8T+4$.

Use the first $k$ odd primes $p_i$. Choose their powers $d_i$ minimally with $d_i\ge16kLp_i$, and set $P=\prod_i d_i$ and $N_i=P/d_i$. On each attempt choose independent uniform nonzero residues $u_i\bmod p_i$. Choose $t_i\equiv u_i\bmod p_i$ within $p_i$ of $d_i w_i/L$. Write $c_0=\sum_i t_i N_i\bmod P$. The construction of the auxiliary prime below gives $\ell>P$ with $\ell c_0\equiv1\bmod P$. Output $n=P\ell$.

Fix a subset $E$ of the augmented items. The root of one with sign $+$ at $\ell$, sign $-$ at blocks in $E$, and sign $+$ at the other blocks has fractional coordinate
$$
\frac{x}{n}\equiv\frac{1}{n}-2\sum_{i\in E}\frac{t_i}{d_i}\pmod{1}.
$$
Indeed $1-2\ell\sum_{i\in E} t_iN_i$ has exactly these local signs. Its negative accounts for the sign $-$ at $\ell$. For empty $E$ the pair is $\pm1$, with one root in the quarter. For nonempty $E$ of weight $S$, set $y=2\sum_{i\in E}t_i/d_i-1/n$. It differs from $2S/L$ by less than $1/(4L)$, using $n> 8L$ and the sum of rounding errors at most $1/(16L)$ before doubling. Since $1\le S\le W\le2T+1$, one has $0<y<3/4$. Only the representative $y$ can lie in the first quarter of the pair $y,1-y$. The cutoff $1/4=2(T+1/2)/L$ lies halfway between the ideal values for $S=T$ and $T+1$, so $y<1/4$ exactly when $S\le T$. Thus $Q(n,1)$ is exactly the augmented count at most $T$.

**Prime generation.** Let $X=P^C$ for a sufficiently large effective absolute integer $C$. Sample a uniformly random integer $\ell\in(P,X]$ in the class $a=c_0^{-1}\bmod P$, and run a deterministic polynomial-time primality test. On failure resample both the local residues and the lift. Every output has $O(\log P)$ bits, and the expected number of attempts is $O(\log P)$.

For the probability bound use Thorner and Zaman's Corollary 1.4 and Remark 1.5 for the sum of $\log p$ over primes $p\le X$ in class $a\bmod P$. Its main term is $\lambda X/\varphi(P)$ where $\lambda=1$, or $\lambda=1-\chi(a)X^{\beta-1}/\beta$ for a single nonprincipal real character and its exceptional zero. Their uniform relative error is at most $1/2$ if $C\ge12$ is chosen large enough: the first error term decays exponentially in $C$, and the second tends to zero uniformly for $X\ge 3^C$. Both constants are effective and $\lambda$ is positive. In our sampling, $c_0\bmod p_i$ is $u_iN_i\bmod p_i$, so $a$ is uniform on units modulo $\prod_i p_i$. Every real character modulo the odd $P$ factors through that product because each kernel of reduction from $d_i$ to $p_i$ has odd order. Hence $\mathbb E[\lambda]=1$ even when the exceptional zero exists. The expected prime weight is at least $X/(2\varphi(P))$. Removing the primes up to $P$ costs at most $P\log P$. Each prime contributes at most $\log X$, and each progression contains at most $X/P+1$ candidates. These bounds give the claimed probability $\Omega(1/\log P)$ per attempt. Every accepted output satisfies the exact sign calculation independently of the analytic time bound. [Thorner–Zaman, Corollary 1.4 and Remark 1.5](https://arxiv.org/pdf/2108.10878#page=3) · [Agrawal–Kayal–Saxena, *PRIMES is in P*](https://doi.org/10.4007/annals.2004.160.781)

## Consequences for centered floor sums

Use the [centered identity](floor-sum-and-log-parity.md#nonadaptive-queries-for-two-distinct-prime-divisors) with $K=n$, $m=\lfloor n/4\rfloor$, $a=n^3$, $q=n^4+1$, and $C=n^2c$, choosing $1\le c<n$. The parity of the sum of $\lfloor at^2/q\rfloor$ on $[C-m,C+m]$, with its computable midpoint contribution removed, is exactly $Q(n,c)\bmod2$. All inputs have $O(\log n)$ bits. This gives a one-query reduction to the homogeneous quadratic floor-sum evaluator.

The randomized result also applies to the [original tail sum](floor-sum-and-log-parity.md#a-quadratic-floor-sum-for-the-roots-above-a-cutoff) at the single cutoff $\lfloor n/4\rfloor$. The lower quarter and the rest of the lower half partition $2^{\omega(n)-1}$ roots of one, an even number on the constructed inputs. The two parities coincide. Both short-index hardness conclusions at $c=1$ use a randomized reduction and a growing number of prime divisors. Whether the short dyadic queries on unfactored two-prime inputs admit a faster evaluator remains open.

The complexity classifications concern polynomial time. With factors supplied, the two-list algorithm already costs $2^{O(b/\log b)}$ for $b=\lceil\log_2(n+1)\rceil$, since the product of $h$ distinct primes is at least $h!$. Obtaining the factors remains a cost of the all-input factoring problem.

## Replay

The small-modulus checks compare the two-list counts with exhaustive congruence tests and literal centered floor sums. For the encoded instances, the subset counts are computed directly and the roots are reconstructed independently from $c$ and the supplied factors.

from bisect import bisect_left, bisect_right
from itertools import product
from math import gcd, isqrt, lcm, prod

def quarter(blocks, c):
    n = prod(blocks)
    terms = [c*(n//d)*pow(n//d, -1, d) % n for d in blocks]
    def residues(half):
        values = [0]
        for u in half:
            values = [(v + sign*u) % n for v in values for sign in (-1, 1)]
        return values
    mid = len(terms)//2
    right = sorted(residues(terms[mid:]))
    total = 0
    for v in residues(terms[:mid]):
        for start in (1, n+1):
            total += bisect_right(right, start-1+n//4-v) - bisect_left(right, start-v)
    return total

for blocks in ([9, 7], [9, 25, 7], [3, 5, 7, 11]):
    n = prod(blocks)
    m, a, q = n//4, n**3, n**4+1
    for c in (1, 2, n//2, n-1):
        assert gcd(n,c) == 1
        C = n*n*c
        count = sum((x*x-c*c) % n == 0 for x in range(1, m+1))
        literal = sum(a*t*t//q for t in range(C-m, C+m+1)) - a*C*C//q
        assert quarter(blocks,c) == count and (literal-count) % 2 == 0

def encode(weights, target):
    items = [*weights, 1]
    W = sum(items)
    L = 16*(W+1)
    # Numerators share the denominator 4L. Slot zero translates the cutoff.
    nums = [L-4*(2*target-W+1)] + [4*w for w in items]
    primes = [3, 5, 7, 11, 13, 17, 19, 23][:len(nums)]
    assert len(primes) == len(nums)
    blocks, coords = [], []
    for p, numerator in zip(primes, nums):
        d = p
        while d < 16*len(nums)*L:
            d *= p
        t = d*numerator//(4*L)
        blocks.append(d)
        coords.append(t+int(t % p == 0))
    n = prod(blocks)
    c = sum(t*(n//d) for t,d in zip(coords,blocks)) % n
    assert gcd(n,c) == 1
    return blocks, c

for weights in ([1], [2,2], [1,3,4,6], [3,5,9,15,24], [1,17,33,98,211,350]):
    subset_sums = [sum(w*x for w,x in zip(weights,bits))
                   for bits in product((0,1), repeat=len(weights))]
    for target in range(sum(weights)+1):
        blocks, c = encode(weights, target)
        count = quarter(blocks,c)
        assert count == sum(int(v<=target) + int(v<target) for v in subset_sums)
        assert count % 2 == subset_sums.count(target) % 2

primes = [3,5,7,11,13]
D = lcm(*(p-1 for p in primes))
def valuation(a,p):
    s = 0
    while a % p == 0:
        a //= p
        s += 1
    return s
weights = [1,3,4]
items = weights+[1]
W = sum(items)
L = 16*(W+1)
blocks, steps = [], []
for p in primes:
    step = p**(valuation(2**(p-1)-1,p)+valuation(D//(p-1),p))
    d = step
    while d < 16*len(primes)*L*step:
        d *= p
    blocks.append(d)
    steps.append(step)
n = prod(blocks)
for target in range(sum(weights)+1):
    nums = [L-4*(2*target-W+1)] + [4*w for w in items]
    z = 0
    modulus = 1

        N = n//d
