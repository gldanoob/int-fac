# Bit cost of the original character probes

KeyBreak's original H.6 sampler and prime-size cap suffice at public degree $d\sim\delta D$ with setup coefficient $2\delta$ and per-epoch retained character coefficient $b+2\delta/3$. Here $D=(\log N/\log\log N)^{1/3}$, $H=D\log\log N$, and the retained occurrence cap is $\exp((b+o(1))H)$. This changes only the implementation of modular arithmetic. It preserves the proposal distribution, simultaneous class separation, accuracy and hidden-root argument. [KeyBreak, (H.22)–(H.27)](https://crypto.sjtu.edu.cn/factoring.pdf#page=138)

Write $S$ for the **bit length** of a proposed probe prime. In the source $S=(2d)!\operatorname{poly}(n)$ up to its stated height factors of polynomial bit-size in the input presentation (the $T^*$ multiplier itself is polynomial in $n$, since it bounds the logarithms); hence $\log S/H\to2\delta/3$. H.24 permits $S\operatorname{poly}(n)$ candidates in all. Candidate selection, base rejection, and probable-prime checks have the original finite caps. A modular powering with an exponent of at most $S$ bits uses $O(S)$ modular multiplications. With fast integer multiplication and division these cost $S^{1+o(1)}$ bit operations each. Inverses and failed inversions can also be computed in $S^{1+o(1)}$ by fast extended gcd. Polynomial arithmetic in degree at most $d$ adds only a polynomial in $n$. Thus a candidate costs $S^{2+o(1)}\operatorname{poly}(n)$ including primality trials, computing $X^p$ modulo the public field polynomial, splitting the degree-one factors, and checking the resulting roots. This bounds unsuccessful operations on composite candidate moduli as well: retain H.6's checked inversions, degree descent and caps. The whole setup costs $S^{3+o(1)}\operatorname{poly}(n)$. The large-integer operations admit sequential bit implementations; no random access to an exponentially long table is required. [Schönhage and Strassen, fast integer multiplication](https://doi.org/10.1007/BF02242355)

There are only polynomially many accepted character probes. Each signed atom in a retained occurrence is reduced at the chosen root and submitted to the original quadratic-character test. Even using modular powering for each symbol gives $S^{2+o(1)}\operatorname{poly}(n)$ per occurrence. Scanning the whole probe list for each retained occurrence is covered, as are the saved evaluations. Failed searches use only local records until retention. The retained cost is therefore $\exp((b+4\delta/3+o(1))H)$. Both estimates use the number of *bits* in the probe, in every modular multiplication and every exponent. They require no improvement of the analytic prime bound or a special number field.

A direct Jacobi evaluation improves the retained coefficient to $b+2\delta/3$. In (H.27) each atom first reduces $a-bu$ modulo the odd candidate $p$ in quasi-linear bit time. Compute its Jacobi symbol, discard the row on zero according to the original rule, and use the sign column as before. For every prime probe the result agrees exactly with the Legendre sign from powering. On a tape with a composite false pass the bounded algorithm still terminates and verifies the final square and every reported divisor. H.6 already charges the probability of the first such false pass. The fast recursive Jacobi algorithm costs $O(M(S)\log S)$ for $S$-bit arguments, where $M(S)=S^{1+o(1)}$ is the multiplication cost. Recursive operand scans and copies fit this bound up to logarithmic factors on tapes. The setup still performs modular powers, which is why the setup estimate stays $2\delta$. [Brent and Zimmermann, Theorem 3](https://arxiv.org/abs/1004.2091)
