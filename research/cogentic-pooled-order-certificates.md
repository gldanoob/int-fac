# Pooling verified orders to split an odd modulus

A list of individually verified order multiples can split an odd modulus even when every single squaring chain gives only global signs. The modular comparison takes polynomial time in the explicit certificates, with no common exponent required. On a dyadic prime interval with uniform Dirichlet character estimates, supplying certificates for more than \(1/4+\delta\) of all primes, all with negative Jacobi sign, suffices for complete factorization of an odd nonsquare input. For a squarefree semiprime the corresponding splitting threshold is \(1/8+\delta\). In both statements \(\delta>0\) is fixed. These results concern use of the supplied certificates. Their generation remains a separate problem. [Individual Jacobi-filtered tests](cogentic-jacobi-exponent-prefilter.md)

## Compare the certificates in the 2-primary group

For each positive certificate \(a_i^{E_i}\equiv1\pmod N\), verify it and set \(g_i=a_i^{E_i/2^{v_2(E_i)}}\bmod N\). In the finite unit group, write \(a_i=a_{i,2}a_{i,\mathrm{odd}}\) for its 2-primary and odd-order components. The exponent kills the odd-order component and raises the other component to an odd power. Thus \(g_i\) generates exactly \(\langle a_{i,2}\rangle\). Skip \(g_i=1\), which includes all odd-order bases. Repeated bases or repeated projected values do not affect the generated group.

For each nonidentity \(g_i\), take its final nonidentity power in the squaring chain. It is an involution. If it differs from \(-1\bmod N\), its difference gcd gives a proper divisor. Otherwise \(g_i\) has the same order at every prime-power component of \(N\), since that final power is nonidentity at each one. Choose an anchor \(h\) of largest order \(2^s\) among the remaining projections. If there is no anchor, the projected group is trivial. In each local cyclic unit group, every projected element has a discrete logarithm to the local image of \(h\), since its order divides \(2^s\).

To test a projected element \(g\), start with \(x=0\). Given agreement of the local logarithms with \(x\) modulo \(2^j\), compute
\[
 z=(g h^{-x})^{2^{s-1-j}}\pmod N,\qquad 0\le j<s.
\]
At each prime power this is \(+1\) or \(-1\) according to the next bit of that local logarithm. If \(z=1\), leave \(x\) unchanged. If \(z=-1\), add \(2^j\) to \(x\). In the remaining case \(z^2=1\) and the proper gcd splits \(N\). Completing all bits gives \(g=h^x\). Thus absence of a split certifies that all projected elements lie in the same cyclic group \(H=\langle h\rangle\) and that \(H\) injects into every prime-power component. This bit comparison is another form of the existing order-decreasing test with a common exponent. [Earlier 2-primary comparison](cogentic-partial-sign-lattice.md#detecting-involutions-with-a-supplied-exponent-multiple)

The calculation can stream the certificates. If a new projection has higher uniform order than the current anchor, test the old anchor relative to the new one before replacing it. If this test succeeds, all previous elements belong to the new cyclic group. An equal or lower order is tested against the current anchor. This uses \(O((\log N)^2)\) modular operations per projection beyond the certificate powering, since \(s\le\log_2N\). A discovered divisor is verified by exact division. Any supplied square-root ratio of known 2-power order can also enter this calculation. For example, modulo 65 the residues 8 and 18 both square to the global value \(-1\). Their quotient is 51, whose difference gcd gives 5. The common-exponent note already contains this example.

## What density of certified primes suffices

Write \(N=\prod_i p_i^{e_i}\), with at least two distinct odd primes, and put \(u_i=v_2(p_i-1)\). The local 2-primary group has order \(2^{u_i}\) also modulo \(p_i^{e_i}\), since the kernel of reduction modulo \(p_i\) has odd order. If the pool has not split \(N\), each certified base belongs to the inverse image \(A\) of \(H\) under the 2-primary projection. Its index in the full unit group is
\[
 [G:A]=2^{\sum_i u_i-s}\ge 2^{\sum_i u_i-\min_i u_i}\ge2.
\]
This tests the actual relationship among the projected elements. Equality of their orders alone gives a weaker condition.

Let \(T=\pi(B)-\pi(B/2)\). The analytic input is a uniform bound \(o(T)\) for the unweighted sum of each nonprincipal Dirichlet character modulo \(N\) over primes in \((B/2,B]\). The [dyadic character estimate](cogentic-dense-exponents.md#majority-generation-on-a-dyadic-interval) gives this under Dirichlet RH when \(B/\log^2(2N)\to\infty\). Its proof uses a fixed taper, a smoothed error \(O_w(\sqrt B\log(2N))\), and the ordinary prime number theorem on the two edge intervals before letting the taper loss tend to zero. Primes dividing \(N\) have proportion \(o(1)\). The indicator of a subgroup or coset is an average of characters on the quotient, with total absolute coefficient sum one. The prime proportion is therefore its unit-group proportion plus \(o(1)\), uniformly even for a subgroup selected from the observed certificates. With a fixed margin \(\delta\), the same proof suffices at \(B\ge C_\delta\log^2(2N)\) for a sufficiently large effective constant.

A pool covering more than \(1/2+\delta\) of the distinct interval primes must split. The earlier majority-generation argument already supplies complete factoring at this threshold via a common exponent. Here the subgroup index gives a sharper conclusion for signed target sets. If all certified bases have negative Jacobi sign, the negative part of \(A\) is empty when the Jacobi character is trivial on \(A\), and otherwise is a single coset of half its size. Thus a pool of more than \(1/4+\delta\) of all interval primes suffices. For squarefree semiprimes with equal \(u_i\), the Jacobi sign on a uniform cyclic subgroup is always positive, so even one negative certificate splits. For unequal \(u_i\), the index bound is at least four, giving the uniform semiprime threshold \(1/8+\delta\). These proportions are relative to all interval primes, with each certified prime counted once.

The same pool gives complete factorization at the \(1/4+\delta\) negative threshold for nonsquare \(N\). On a composite cofactor \(D\mid N\) with at least two distinct primes, reduce the original certificates modulo \(D\). If the pooled comparison does not split \(D\), the bases lie in the preimage in \(G\) of a subgroup of index at least two in the units modulo \(D\). Reduction of units is surjective, so that preimage has the same index in \(G\). Its intersection with the original negative Jacobi coset is again empty or half the preimage. The uniform bound still uses modulus \(N\) and the original target interval. Thus each such cofactor can be split using the same pool, and prime powers can be recognized separately. The number of recursive calls is polynomial in \(\log N\). No order-generator supply on the new cofactors is needed.

The [exact replay](../experiments/cogentic-pooled-order-certificates.py) checks the streamed decision against 2,268 directly generated 2-primary subgroups and verifies 38 signed subgroup sizes. Every returned factor is checked by integer division.
